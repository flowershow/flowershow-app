# Edit this page Button

## Configuration

>[!important]
> This feature requires your repository to be public on GitHub.

Enable the edit button by adding this to your `config.json`:

```json
{
  "showEditLink": true
}
```

## Troubleshooting

If the edit button isn't appearing:

1. Verify your repository is public
2. Check your `config.json` syntax
3. Try clearing your browser cache

For more details and best practices, see our [[flowershow-cloud-edit-this-page-button|blog post]].
